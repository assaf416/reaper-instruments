# Guitar Legends Presets - Tukan Studios Guitar Station S2

This guide provides detailed setup instructions for 10 iconic guitar sounds using the Tukan Studios Guitar Station S2 plugin. Each section includes recommended amp, cabinet, and effect settings.

## Setup Instructions

For each preset below:
1. Load **Guitar Station S2 (Tukan)** on a guitar track
2. Configure the amp, cabinet, and effects as specified
3. Adjust gain/master levels to match your input signal
4. Save as a preset in Reaper for future use

**Note:** Exact preset values depend on your specific setup and input signal level. These are guidelines based on the character of each guitarist's tone.

## 1. David Gilmour - Pink Floyd (Shine, Money, Comfortably Numb)

**Character:** Warm, sustaining lead tone with vocal-like bending, smooth overdrive, lush reverb and chorus

### Tone Controls
| Setting | Value | Notes |
|---------|-------|-------|
| **Bass** | 6-7 | Warm foundation, full low-end |
| **Mid** | 5-6 | Slight mid-scoop for clarity |
| **Treble** | 7-8 | Bright presence for sustain |
| **Bright** | On | Shimmer and definition |
| **Pre-Gain** | 7-8 | Smooth overdrive, not aggressive |
| **Distortion** | 2-3 | Barely engaged, natural compression |

### Amp & Cabinet
| Setting | Recommendation |
|---------|-----------------|
| **Amp** | British Warm (Warm) or Blues (Clean with grit) |
| **Power** | 50-100W for organic breakup |
| **Cabinet** | British 1x12 (Closed back) - warm, controlled |
| **Microphone** | Ribbon or SM57 (Mid) for smooth tone |

### Effects Order
| Effect | Setting | Character |
|--------|---------|-----------|
| **Gate** | Threshold -20dB | Only open for sustained notes |
| **Distortion/OD** | ENABLED - Soft Clip | Pre-amp saturation, smooth |
| **Modulation** | CHORUS - Medium depth (40-60%), slow rate (0.5-1Hz) | Iconic Gilmour shimmer |
| **Delay** | 375ms (dotted eighth @ 120BPM) | Adds space and dimension |
| **Reverb** | Spring Reverb, 50-60% mix | Vintage plate-like ambience |

### Performance Tips
- Use the **mod wheel** to blend dry/wet on delay/reverb
- Bend strings with sustain - the chorus and reverb create the "floating" effect
- Let notes ring and decay naturally (long release)
- Vibrato is subtle - use sparingly

## General Configuration Tips

### Input Level Setting
- **Pre-Gain slider**: Adjust until your input signal is hitting around -6dB on the input meter
- Too hot = distortion at input stage (less musical)
- Too quiet = need excessive amp gain (noisy)

### Output Level
- **Master/Output**: Set so your guitar matches other tracks at -3dB to -6dB RMS
- Leave headroom for peaks

### Pedal Order Reference
The standard pedal order (left to right):
1. **Compressor** (dynamics control)
2. **Distortion/Overdrive/Fuzz** (tone generation)
3. **Modulation** (Chorus, Flanger, Phaser)
4. **Delay** (time-based)
5. **Reverb** (ambient)
6. **Master Output**

### Cabinet/Microphone Pairings
- **British 1x12 + Ribbon** = Smooth, warm, vintage
- **British 1x12 + SM57 (Mid)** = Punchy, defined, present
- **British 2x12 + SM57 (Near)** = Full body with articulation
- **British 4x12 + SM57 (Near)** = Aggressive, roaring, loud

## How to Create These Presets in Reaper

1. **Configure the first preset** (Gilmour) exactly as shown above
2. In Guitar Station S2, click **"Save"** (preset list)
3. Enter the preset name: `Gilmour Shine`
4. Repeat for each guitar style
5. Your presets are saved in REAPER/Effects/Tukan/ and available in the plugin dropdown

Alternatively:
- Right-click the Guitar Station S2 plugin name
- Select **"Save FX Preset"**
- Name it `GuitarRig - Gilmour` etc.
- It will be saved in REAPER's FX Preset folder

## Inspiration Sources

- **David Gilmour**: Black Strat through Hiwatt amps, Fender Twin reverb, iconic use of Binson Echorec delay
- **The Beatles**: Vox AC30 (Lennon), Fender Telecaster + Fender Bassman (McCartney), natural amp breakup
- **Jimi Hendrix**: Marshall stack, Fuzz Face and UniVibe pedals, Marshall JCM800 tone
- **Deep Purple**: Stratocaster through Marshall stack, purple-tinted, heavy sustain tone
- **Iron Maiden**: British amp tone with high-gain, dual-lead guitar harmonies (Adrian Smith/Dave Murray)
- **Nirvana**: Boss DS-1 distortion (Kurt Cobain), Fender Jaguar, Marshall JCM 800, heavily compressed tone
- **Queen**: Brian May's Red Special through custom amps, lush reverb and chorus, orchestral warmth
- **Dire Straits**: Mark Knopfler's Fender Strat through Fender combo amps, warm clean tone, fingerstyle articulation
- **Metallica/Megadeth**: Marshall JCM800 or similar high-gain British amp, tight distortion, gate control for precision
- **Rage Against the Machine**: Tom Morello's experimental tone blending heavy distortion with clean funky rhythms, wah effects

Each tone is a starting point - adjust to your guitar, amplifier, and playing style!
