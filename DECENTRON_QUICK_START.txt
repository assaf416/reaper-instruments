SETUP (120 seconds - SUPER EASY!)
═══════════════════════════════════════════════════════════════════════════════

STEP 1: Create Tracks
  • Open Reaper project
  • Run: Actions > Search "Mellotron_DecenTron_Setup.lua"
  • Click "Run"
  ✓ Done! 4 tracks auto-created with routing

STEP 2: Load Samples (3 tracks)
  For EACH tape track:

  1. Add FX > ReaSampler
  2. Click "Open sample..."
  3. Navigate to: decent-sampler-files/melotron/DecenTron 1.0.0/Samples/[Instrument]/
     Examples:
     • MkIIFlute/ (Tape 1 default)
     • M300A/ (Tape 2 default)
     • StringSection/ (Tape 3 default)
  4. Select ANY .wav file (e.g., C4.wav)
     → ReaSampler auto-maps all 35 notes!
  5. Enable ✓ Resample
  6. Enable ✓ Note on MIDI key
  7. Click OK

STEP 3: Play!
  • Create MIDI item
  • Play keyboard
  • Mellotron plays! 🎵

KEYBOARD TECHNIQUE
═══════════════════════════════════════════════════════════════════════════════

🎹 SUSTAIN PEDAL
  Press sustain when holding notes for smooth tape transitions

🎹 VELOCITY DYNAMICS
  • Soft (20-50):    Muted, intimate
  • Medium (60-100): Natural tone
  • Hard (110-127):  Bright, attacking

🎹 LAYERING
  • Play 2-3 notes to create lush harmonies
  • Use Tape 1 for melody, Tape 2-3 for harmony

🎹 PANNING
  Create stereo width:
  • Tape 1: Center (0)
  • Tape 2: Left (-30 to -50)
  • Tape 3: Right (+30 to +50)


PERFORMANCE SETTINGS
═══════════════════════════════════════════════════════════════════════════════

Add these to master bus for vintage character:

REVERB
  Type: Hall or Spring reverb
  Wet: 50-70%
  Decay: 2-3 seconds
  → Creates classic 70s Mellotron space

COMPRESSION
  Ratio: 2:1 to 3:1
  Attack: 50ms
  Release: 200ms
  → Tape-like glue and warmth

EQ
  Boost 2-4 kHz (presence)
  Roll off 10 kHz+ (warmth)
  Slight 100 Hz presence
  → Vintage character

OPTIONAL EFFECTS
  Chorus: Light modulation for width
  Tape Saturation: Add harmonic warmth
  Soft Clipper: Smooth peaks

TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

PROBLEM: No sound
  ✓ Check ReaSampler shows green "loaded"
  ✓ Verify sample folder path is correct
  ✓ Check track volume levels
  ✓ Enable ReaSampler processing
  ✓ Check master volume > 0%

PROBLEM: Some notes missing
  ✓ Verify ALL 35 .wav files in folder
  ✓ Try loading a different sample from folder
  ✓ Check folder name spelling (case-sensitive on Mac/Linux)

PROBLEM: Clicking/pops
  ✓ Increase audio buffer size (64→256 samples)
  ✓ Lower ReaSampler quality if needed
  ✓ Check track levels aren't clipping

PROBLEM: Can't find samples
  ✓ Sample path: decent-sampler-files/melotron/DecenTron 1.0.0/Samples/
  ✓ Each folder name matches instrument (e.g., MkIIFlute, StringSection)
  ✓ Each folder contains 35 .wav files (C2.wav through F#5.wav)
