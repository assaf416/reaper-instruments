PERFORMANCE TIPS
════════════════════════════════════════════════════════════════════

🎹 KEYBOARD TECHNIQUE
   • Use Sustain pedal for smooth tape transitions
   • Play legato for authentic sound
   • Light velocity (30-50) = soft/muted
   • Medium velocity (60-100) = natural tone
   • Hard velocity (110-127) = bright/attacking

🎚️ REAL-TIME MIXING
   • Fade in Tape 2 during verse 2
   • Add Tape 3 for chorus sections
   • Dial up Saturation for climax
   • Use panning for stereo movement

🎼 LAYERING TRICKS
   • Keep Tape 1 as main melodic element (100%)
   • Use Tape 2 as harmonic bed (40-70%)
   • Add Tape 3 for texture (20-50%)
   • Never max all three at once (sounds muddy)

TROUBLESHOOTING QUICK FIX
════════════════════════════════════════════════════════════════════

NO SOUND?
  → Check ReaSampler shows green checkmark
  → Verify sample file is loaded
  → Check track levels (not at 0)
  → Check Master Volume slider > 0%

AUDIO CLICKS?
  → Lower Wow & Flutter (reduce wobble)
  → Increase audio buffer size
  → Lower Saturation setting

WON'T LOAD?
  → Restart Reaper
  → Drag .jsfx file directly to track FX

RECORDING PERFORMANCE
════════════════════════════════════════════════════════════════════

Best Practice Workflow:

1. Create MIDI track with Mellotron
2. Create automation lane for tape mixing
3. Record MIDI performance
4. Record parameter automation changes
5. Add reverb/compression on master
6. Export stereo mixdown
7. Done!


RECOMMENDED MASTER BUS EFFECTS (In Order)
════════════════════════════════════════════════════════════════════

1. Mellotron.jsfx              (Mixer plugin)
2. Parametric EQ               (Boost 2-4kHz, roll off 10kHz+)
3. Chorus                      (Rate: 1.5Hz, Depth: 30%)
4. Reverb                      (Type: Hall/Spring, 2-3 sec)
5. Compressor                  (Ratio: 2:1, Attack: 50ms)
6. Soft Clipper                (Optional warmth)


TEMPO SYNC & MATCHING
════════════════════════════════════════════════════════════════════

For best results, match tape settings to song style:

SLOW BALLAD (60-80 BPM)
  → Wow: 20% | Saturation: 40% | Long sustain times

MID-TEMPO ROCK (100-130 BPM)
  → Wow: 35% | Saturation: 50% | Medium note length

UPTEMPO (130+ BPM)
  → Wow: 25% | Saturation: 45% | Shorter articulate notes
