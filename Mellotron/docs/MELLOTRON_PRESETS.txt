HOW TO USE THESE PRESETS
═════════════════════════════════════════════════════════════════════════════════

METHOD 1: Manual Setup (Easiest for learning)
──────────────────────────────────────────────
1. Open Mellotron.jsfx in your FX window
2. For each preset, manually adjust sliders to match the values above
3. Test by playing notes on your keyboard
4. Save your favorite configurations


METHOD 2: Reaper Preset System
───────────────────────────────
1. Configure the Mellotron.jsfx with your first preset
2. In the FX window, click the preset dropdown
3. Select "Save preset as..."
4. Name it (e.g., "Classical_Strings_YES")
5. Save and repeat for each preset


METHOD 3: JSFX Automation
──────────────────────────
1. Create preset variations by automating slider changes
2. Record parameter changes over time
3. Play back for dynamic tape mixing during performance

MIXING REAL-TIME DURING PERFORMANCE
═════════════════════════════════════════════════════════════════════════════════

For live performance, you can dynamically mix tapes:

Technique 1: Fade-In Secondary Tapes
  - Start with Tape 1 at 100%, Tape 2-3 at 0%
  - Gradually increase Tape 2/3 during the song
  - Use faders for smooth blending

Technique 2: Tape Switching
  - Quickly change Tape Selection to different sounds
  - Keeps same level but changes timbre
  - Works well for verse/chorus variations

Technique 3: Panning Dynamics
  - Use pan to create stereo movement
  - Move tapes L/R during builds or choruses
  - Creates sense of space and depth

Technique 4: Saturation Swells
  - Increase Tape Saturation for climactic moments
  - Dial back for clean sections
  - Adds dynamic energy and character

Tips for Creating Your Own Presets:
  - Start with one tape, add layers
  - Experiment with panning for width
  - Tape Saturation = character, Wow = vintage feel
  - Less is often more (avoid 100% on all three tapes)
  - Save frequently and name descriptively
  - Trust your ears over the numbers!
