              ▲                      ▲                 ▲

AUDIO SIGNAL FLOW
=================

MIDI Input (from keyboard/controller)
  ↓
  ├→ Track 1 (ReaSampler) ──────┐
  │                             ├→ MELLOTRON.jsfx Mixer ──→ Master Out
  ├→ Track 2 (ReaSampler) ──────┤
  │                             ├→ (Processes 3 tape mix)
  └→ Track 3 (ReaSampler) ──────┘


STEP-BY-STEP SETUP
==================

1. QUICK METHOD (Recommended)
   ─────────────────────────
   ✓ Open Reaper project
   ✓ Run: Mellotron_Setup.lua
   ✓ DONE! (Tracks auto-created and configured)


2. MANUAL METHOD
   ──────────────

   A. Create 3 Audio Tracks
      • Reaper menu: Insert > Insert new track(s)
      • Create 3 tracks
      • Name them: "Tape 1 - Flute", "Tape 2 - Cello", "Tape 3 - Violins"
      • Give them distinct colors (optional)

   B. Add ReaSampler to Each Track
      • Track 1 → FX > Add FX → ReaSampler
      • Track 2 → FX > Add FX → ReaSampler
      • Track 3 → FX > Add FX → ReaSampler

   C. Load Samples
      • Each ReaSampler:
        ├─ Click "Open sample..."
        ├─ Navigate to: samples/Mellotron/
        ├─ Select: sample_000.wav
        └─ Confirm

   D. Configure ReaSampler
      • Each instance:
        ├─ Enable ✓ Resample
        ├─ Set "Note on MIDI key" mode
        └─ Set quality to "High" or "Very High"

   E. Route to Master Bus
      • Track 1 → I/O → Master
      • Track 2 → I/O → Master
      • Track 3 → I/O → Master

   F. Add Mellotron Mixer
      • Master Track → FX > Add FX → Mellotron.jsfx
      • This provides the mixing UI

MIXING STRATEGIES
=================

LUSH STRING PAD:
  Tape 1: M400 String Section (100%)
  Tape 2: M400 Cello (60%)
  Tape 3: M400 Choir (40%)
  → Set Wow to 35%, Saturation to 50%

ORCHESTRAL BRASS:
  Tape 1: Gc3 Brass (100%)
  Tape 2: M400 Woodwind2 (70%)
  Tape 3: M400 String Section (40%)
  → Set Wow to 25%, Saturation to 40%

AMBIENT FLUTE:
  Tape 1: MKII Flute (100%)
  Tape 2: MKII Flute (80% - pan left)
  Tape 3: M400 Choir (50% - pan right)
  → Set Wow to 50%, Saturation to 60%

SOLO CELLO:
  Tape 1: M400 Cello (100%)
  Tape 2: Off (0%)
  Tape 3: Off (0%)
  → Set Wow to 20%, Saturation to 30%


EFFECTS RECOMMENDATIONS
=======================

For authentic Mellotron character, add effects AFTER the mixer:

Master Track FX Chain:
  1. Mellotron.jsfx         (Mixer plugin)
  2. Parametric EQ          (boost 2-4kHz, roll off 10kHz+)
  3. Chorus                 (simulates tape wobble)
  4. Reverb                 (spring/hall, 2-3 seconds)
  5. Compressor             (light 2:1 ratio, 50ms attack)
  6. Soft Clipper           (optional warmth)


KEYBOARD PLAYING TIPS
=====================

✓ Use SUSTAIN pedal for smooth tape transitions
✓ Layer melodies by keeping multiple notes pressed
✓ Vary velocity (soft: 30-50, medium: 60-100, hard: 110-127)
✓ Use CC#1 (mod wheel) to control overall mix in real-time
✓ Record automation for tape level changes
✓ Use portamento/glide time in DAW for realistic tapes


TROUBLESHOOTING
===============

Problem: No Sound
  ✓ Check all track levels (should not be at minimum)
  ✓ Verify ReaSampler shows green "loaded" indicator
  ✓ Check master volume in Mellotron.jsfx (should be > 0%)

Problem: Audio Clicks/Pops
  ✓ Lower Wow & Flutter setting
  ✓ Increase audio buffer size (Reaper > Preferences > Audio)
  ✓ Lower Tape Saturation value

Problem: Mellotron.jsfx Won't Load
  ✓ Restart Reaper
  ✓ Check FX list loads other plugins
  ✓ Try loading directly into FX chain (drag .jsfx file)

Problem: Tape Sounds Thin
  ✓ Increase Tape Saturation for warmth
  ✓ Layer multiple tapes together
  ✓ Add Reverb on master bus
