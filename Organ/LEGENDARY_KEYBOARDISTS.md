## Usage Tips

- **Vibrato/Chorus Scanners:** Each preset uses scanner settings that match the artist's signature approach to vibrato color
  - V1 (codes 1, 513) = subtle, tight modulation
  - V2 (codes 2, 514) = medium, warm modulation
  - V3 (codes 3, 515) = deep, lush modulation
  - Codes 641-643 = same scanner with upper manual vibrato enabled

- **Leslie Settings:** Matched to the original recordings
  - Slow (1) = smooth, shimmering
  - Fast (2) = dramatic, spinning effect
  - Stop (0) = dry, direct sound

- **Overdrive/Reverb:** Calibrated for each piece
  - Heavy overdrive for Emerson and Lord's power
  - Subtle reverb for Banks' atmospheric work
  - Percussion emphasis for Wakeman's rhythmic approach

## Inspiration Sources

These presets capture the essence of classic progressive rock organ playing:
- **Rick Wakeman's Yes period** (1971-1974): technically brilliant, harmonically dense
- **Tony Banks' Genesis evolution**: from Genesis II onwards, more atmospheric and cinematic
- **Keith Emerson's ELP classics** (1970-1975): virtuosic, theatrical, innovative
- **John Lord's Deep Purple era**: bluesy, powerful, groove-oriented

Each preset is a starting point for your own explorations of these legendary tones.
