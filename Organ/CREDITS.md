# Credits and licenses - Organ

* **`original/LordOfTheRinks.jsfx`** - *Lord of the Rinks Tonewheel Organ (setBfree port)* by **chmaha**
  (part of the REAPER "DSP to JSFX / Plugin Ports" collection). JSFX code released under **GPLv3+**.
  Included here unmodified, with its original header.
* It is a port of **setBfree** by Fredrik Kilander, Robin Gareus, Ken Restivo and Will Panther
  (https://github.com/pantherb/setBfree, GPLv2+). INIT program suggested by Ryan McAlister.
* **`OrganSingle.jsfx`** is a modified copy of the above and is therefore also **GPLv3+**. Changes: single upper manual
  and its keyboard only, all MIDI channels play the upper manual, the setBfree programs replaced by a custom 20-preset
  bank with preset buttons, and a reduced settings page. The tone generator, scanner, percussion, overdrive, reverb and
  Leslie code are unchanged.
